Plastic Waste Reporter — classroom prototype.

User page: upload photo, description and GPS location, then submit.
Cleaning Dashboard: view all stored reports and change Reported -> In Progress -> Cleaned.

Open index.html first, submit a report, then open admin.html.

Important: reports are stored in the browser with localStorage. This prototype is NOT connected to BBMP or a public cloud database. A production system would need a backend/database and authorized civic integration.
